CERTIFICATE SCANS
=================

Default filenames expected by js/data.js:

  1.jpg  →  Agentic AI Hackathon (Product Space x Twinmind)
  2.jpg  →  Frontend Web Developer (Prodesk IT)
  3.jpg  →  Web Developer (Elem Consumer Tech)
  4.jpg  →  Advanced Diploma in IT

Any aspect ratio works — cards crop to 4:3, and clicking one opens the
full uncropped image in a lightbox.

Format: JPG or PNG, at least 1200px on the long edge so the text stays
readable when zoomed. Keep each under ~500KB.

If a scan is missing, the card still renders with the title and issuer,
and the lightbox tells you which file to add.

To add more certificates, append entries to CERTIFICATES in js/data.js.
