DROP YOUR PHOTOS HERE
=====================

Name them exactly:

  1.jpg   2.jpg   3.jpg   4.jpg   5.jpg

Recommended: portrait / 4:5 ratio, ~1200 x 1500px, under 400KB each
(compress at squoosh.app — keeps the Lighthouse score high).

If a file is missing, the card gracefully falls back to a coloured
gradient panel, so the site never looks broken while you gather images.

Want more or fewer than 5? Just add/remove a <figure class="pcard">
block inside #photoStage in index.html — the scroll maths adapts
automatically to however many cards exist.
